# Owner-Facing Investigation Report

## Required sections
1. Business name and identity confirmation
2. Scope, date, and inspected sources
3. Executive summary with limited, factual language
4. Findings (each observation, evidence, uncertainty, possible effect)
5. What we could not verify
6. Questions for owner
7. Proposed fix, contingent on owner confirmation
8. Evidence appendix with links and timestamps

## Language standards
Use 'We observed...' and 'This may create friction...' not 'You are losing $X' or 'Your team never responds.' A missing UI element is not proof of lost revenue. A sampled AI search result is not a universal ranking.

## Display rules
Every finding has clickable source reference or clearly marked manual observation; timestamps and query parameters where relevant. If the source is no longer available, preserve permitted metadata and label status. No raw private group discussions in public-facing reports without appropriate permission.

## Report statuses
Draft → evidence_review → approved_internal → approved_to_share. No automatic publishing. An approved report is not proof that the business agreed with the diagnosis.
